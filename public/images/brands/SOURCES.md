# Platform logo sources

- Discord: original full logo from https://discord.com/branding, https://cdn.prod.website-files.com/6257adef93867e50d84d30e2/66e3d741b8346ed0ecebb501_Logo.svg
- Steam: Valve's full logo from https://store.steampowered.com, https://store.akamai.steamstatic.com/public/shared/images/header/logo_steam.svg
- Riot Games: original full black lockup from https://www.riotgames.com/en/press, Riot Games RGB Logos (Web), 002_RG_2021_FULL_LOCKUP_BLACK.png.
- Epic Games: the complete badge from https://github.com/simple-icons/simple-icons/blob/develop/icons/epicgames.svg.

Original geometry is preserved. The interface uses alpha masks for its shared gray-blue presentation.

The symbol-only Discord and Steam assets use the original SVG geometry with a symbol-only viewBox. Riot uses the original 001.1_RG_2021_LOGOMARK_BLACK.png from the same official press kit.
